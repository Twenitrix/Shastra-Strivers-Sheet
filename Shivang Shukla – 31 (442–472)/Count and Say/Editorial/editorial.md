# Editorial: Count and Say

## Problem Overview

Given a positive integer `n`, return the `n`th term of the Count and Say sequence.

The sequence starts with `"1"`. Each next term is generated by describing the consecutive groups of identical digits in the previous term.

**Example:**

- `1` → `"1"`
- `2` → `"11"` (one 1)
- `3` → `"21"` (two 1s)
- `4` → `"1211"` (one 2, then one 1)
- `5` → `"111221"` (one 1, one 2, then two 1s)

## Approach: Run-Length Encoding

The key observation is that every term depends on the previous term.

Start with `"1"` and generate the next term repeatedly until reaching `n`.

For each term:
1. Traverse the current string from left to right.
2. Count consecutive occurrences of the same digit.
3. Append the count followed by that digit to the next string.
4. Replace the current string with the newly generated string.

Using `StringBuilder` makes constructing each term efficient.

## Algorithm

1. Initialize the current string as `"1"`.
2. Repeat the generation process from term `2` through term `n`.
3. For every group of identical consecutive digits, calculate its length.
4. Append the group's length and digit to a new string.
5. Update the current string with the new string.
6. Return the current string.

## Java Implementation

```java
class Solution {
    public String countAndSay(int n) {
        String s = "1";

        for (int i = 2; i <= n; i++) {
            StringBuilder sb = new StringBuilder();
            int j = 0;

            while (j < s.length()) {
                char ch = s.charAt(j);
                int count = 0;

                while (j < s.length() && s.charAt(j) == ch) {
                    count++;
                    j++;
                }

                sb.append(count);
                sb.append(ch);
            }

            s = sb.toString();
        }

        return s;
    }
}
```

## Dry Run

For `n = 5`:

- Term 1: `"1"`
- Term 2: `"11"` — one `1`
- Term 3: `"21"` — two `1`s
- Term 4: `"1211"` — one `2`, followed by one `1`
- Term 5: `"111221"` — one `1`, one `2`, followed by two `1`s

Therefore, the output is `"111221"`.

## Complexity Analysis

Let \(L_i\) denote the length of the \(i\)th term.

- **Time Complexity:** \(O(L_1 + L_2 + \cdots + L_n)\), because each generated term is traversed to construct the next term.
- **Space Complexity:** \(O(L_n)\) auxiliary space for storing the current and next terms, up to constant factors.

## Key Takeaways

- Each term is generated from the previous term.
- Consecutive identical digits are counted as a group.
- Append the count first, followed by the digit.
- `StringBuilder` is useful for efficiently constructing strings.
